
Real-time is opt-in. Wire __NAME__Hub in its module (Program.cs stays the registry):

  // AddServices
  services.AddSignalR();
  // Map (after the module's other routes)
  app.MapHub<__NAME__Hub>("/hubs/__NAME_LOWER__");

Rooms are scoped to the caller's org: a room key names a group of the caller's own org, so no client can join or
broadcast into another org's room. Narrow MayEnter to the module's participation rule before shipping a room that
is not org-wide.

A WebSocket can't send an Authorization header, so for hub paths the access token must
ride the query string. With Skies.Framework.Auth's JWT, add to AddServices
(using Microsoft.AspNetCore.Authentication.JwtBearer):

  services.Configure<JwtBearerOptions>(JwtBearerDefaults.AuthenticationScheme, o =>
      o.Events = new JwtBearerEvents
      {
          OnMessageReceived = ctx =>
          {
              var token = ctx.Request.Query["access_token"];
              if (!string.IsNullOrEmpty(token) && ctx.Request.Path.StartsWithSegments("/hubs"))
                  ctx.Token = token;
              return Task.CompletedTask;
          },
      });

Requires Skies.Framework.Auth (run `skies g auth` if you haven't). Scaling past one instance?
Add a backplane: services.AddSignalR().AddStackExchangeRedis(connection).
